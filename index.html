About

I am a researcher working on software and firmware security, with a focus on vulnerability detection for the Internet of Things and Industrial Internet of Things. My research explores how program representations and machine learning can support the analysis of source code and firmware binaries.

Research Interests

  • IoT and IIoT firmware security and vulnerability detection
  • Source-code and binary program analysis
  • Machine learning and large language models for software security
  • Cross-architecture binary similarity and vulnerability retrieval
